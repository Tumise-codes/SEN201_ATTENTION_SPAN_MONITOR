SEN 201 SDLC PROJECT - HUMAN ATTENTION SPAN MONITORING TIMER

1. Planning Phase
The Human Attention Span Monitoring Timer is designed to monitor how long a user stays focused on a particular task. The system helps prevent fatigue by alerting the user when the recommended attention time is exceeded.

2. Requirements Analysis
Functional Requirements
- System should accept task name
- System should accept attention time limit
- System should simulate time tracking
- System should alert user when time is exceeded

Non-Functional Requirements
- System should be easy to use
- System should run in a console environment
- System should provide clear messages

3. System Design
- The system is designed as a console-based Python program.
It consists of:
- Input module
- Timer simulation logic
- Alert output module

4. Implementation
- The system is implemented using Python programming language.
- Variables and loops are used to simulate attention tracking.

5. Testing
- The system is tested by entering different tasks and attention time limits to confirm correct alert behavior.

6. Deployment
- The system is deployed by uploading the source code to GitHub for public access.

7. Maintenance
- Future enhancements may include breaks scheduling, graphical alerts, or data logging.
